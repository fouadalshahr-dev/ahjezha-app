# تطبيق احجزها (Ahjezha App)

نظام إلكتروني متكامل لحجز الملاعب الرياضية مع دعم الدفع حصراً عبر **الشام كاش (Cham Cash)** وإدخال رقم الهاتف السوري ورمز حساب الشام كاش الخاص بكل ملعب.

## المميزات:
- طريقة الدفع مقتصرة حصراً على **الشام كاش**.
- اختيار الملعب مع ظهور رمز حساب الشام كاش الخاص به تلقائياً.
- التحقق من صحة رقم الهاتف المحمول السوري (`09xxxxxxxx`).
- حقل إلزامي لإدخال رقم عملية التحويل (`Transaction ID`).
